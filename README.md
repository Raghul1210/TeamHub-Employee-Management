# TeamHub - Employee Management System

Built by **Raghul R** | [LinkedIn](https://linkedin.com/in/raghul2233)

A web application to add, view, edit and delete employee records.

## Tech stack
- ASP.NET MVC (C#)
- SQL Server with stored procedures
- Bootstrap and custom CSS

## Features
- Full CRUD (Create, Read, Update, Delete)
- Stored procedures for all database operations
- Input validation (10-digit phone number, required joining date)
- Card-style responsive design

## How to run
1. Create a SQL Server database named MrRsyestem and the table EmployeeDetailes.
2. Create the stored procedures: EmployeeInsert1, ListEmployee, EmployeeDetaile, EmployeeUpdate, DeleteEmployee.
3. Open the solution in Visual Studio and press F5.
